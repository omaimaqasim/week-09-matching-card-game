🎯 One golden rule (remember this)
When using CSS Grid → do NOT set width on the items
CSS Grid automatically controls the width of its items using columns.
If we manually set width on grid items, grid and item fight, causing gaps and broken layout.
Grid does not control height; height comes from content or other properties.
aspect-ratio controls the shape (width : height), not the actual size.
Using aspect-ratio lets grid control width and element calculate height automatically.
This avoids layout issues and makes the design responsive and clean.

Golden rule:
👉 Let grid decide width, use aspect-ratio to decide height.
