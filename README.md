# 🃏 Matching Card Game

A simple matching card game built using **HTML, CSS, and JavaScript**.  
Flip the cards, find matching pairs, and try to win in the minimum number of moves.

---

## ✨ Features

- Card flip animation (3D effect)
- Random card shuffle
- Move counter
- Match counter
- Restart button
- Responsive design (mobile-friendly)
- Simple and clean UI

---

## 🛠 Technologies Used

- HTML
- CSS
- JavaScript

---


---

## 🎮 How to Play

1. Click on a card to flip it
2. Flip two cards at a time
3. If the cards match, they stay open
4. If not, they flip back after a short delay
5. Match all pairs to win the game
6. Click **Restart** to play again

---

## 🧠 Game Logic Overview

- Cards are shuffled randomly when the game starts
- Only two cards can be flipped at a time
- Board is locked while checking for a match
- Moves are counted after every two flips
- Game ends when all pairs are matched

---

## 📱 Responsive Design

- 4 cards per row on larger screens
- 3 cards per row on smaller screens
- Card size maintained using `aspect-ratio`
